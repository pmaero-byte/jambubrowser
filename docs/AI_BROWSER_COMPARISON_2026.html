04

The honest summary

Where Jambu is the only one doing it

  • Sovereignty at $0. MIT-licensed and self-hostable — you can run the whole engine with local models and pay no subscription to anyone.
  • Auditing, not just answering. The specialised auditors + signed evidence turn browsing into a defensible, CI-ready artefact — no other agentic browser ships this.
  • Own search + own egress. A private multi-engine index and fail-closed Tor/VPN routing instead of a single vendor's search cloud.
  • It is a platform. 52 MCP tools, an A2A card and ~290 endpoints mean other agents can hire it — the others are closed surfaces.
  • Proof, not vibes. Tamper-evident logs and Ed25519 evidence bundles that a third party can verify independently.

Fair caveats — where Jambu is behind

  • Polished everyday browsing. Native tabs are pre-production (downloads, find, copy disabled). Comet, Dia and Edge are finished browsers today.
  • Distribution. PyPI / Homebrew packaging is documented but not published; the competitors are one-click installs.
  • Zero-setup. Jambu asks you to run an engine and pick a model — the others just open.
  • Single-node mesh. Decentralised pieces are exercised by a two-engine test, but no second node runs in CI yet.
  • No billing. The paid tiers exist in the model; checkout is still a stub.

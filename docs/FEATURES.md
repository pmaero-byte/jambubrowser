# Feature Map: Jambubrowser Evolution

This document maps the 130+ iterations of development that have transformed Jambubrowser into a world-class sovereign research agent.

## 🧠 Intelligence & Reasoning
- **Autonomous Swarm Research**: Decomposes complex queries into parallel sub-tasks.
- **Recursive RAG**: Multi-round research that builds on previous findings.
- **Consensus Debate**: Optimist vs. Skeptic persona audit for bias elimination.
- **Jambu Snap (Short-Circuit)**: Instantaneous conversational response for greetings.
- **Agent Intuition**: Pre-research hypothesis generation.
- **Cross-Session Stitching**: Semantic recall of research from previous weeks.

## 🌐 Exploration & Sovereignty
- **Hybrid Workspace**: Persistent agent sidebar alongside a standard browser view.
- **Deep Trust Bridge**: Clicking citations navigates the browser to the original source.
- **Deep Web Integration**: Onion routing via integrated Tor tunnel.
- **Forensic Safety**: Stateless browser instances with zero-data persistence.
- **Autonomous Risk Assessment**: Malicious link pre-scanning via vision/LLM.
- **Credential Vault**: Local-only encrypted storage for paywall traversal.

## ⚡ Action & Precision (Computer Use)
- **Visual Grounding**: The agent "sees" the page and identifies buttons/forms.
- **Coordinate Clicking**: High-precision interaction bypassing fragile CSS selectors.
- **Self-Improving Toolbox**: Agent autonomously writes and persists Python scripts.
- **Temporal Scheduling**: Automated mission monitor for background research.
- **Dynamic Resource Scaling**: Adjusts concurrency based on available system RAM.

## 🎨 Professional Interface
- **Premium Glass UI**: High-fidelity translucent design with deep macOS Sequoia blurs.
- **Floating Command Bar**: Minimalist pill-shaped input hub.
- **3D Intelligence View**: Interactive WebGL mapping of your local knowledge vault.
- **Unified metrics**: Real-time tracking of TPS, RAM, and Compute Load.
- **Mobile Network Bridge**: QR-code pairing for secure "Brain" access on-the-go.

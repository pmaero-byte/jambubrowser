CLI First

Terminal-native workflow. jambu audit https://yoursite.com — that's it.

Audit in 3 Commands

# Install and authenticate
$ pip install jambubrowser
$ jambu auth jambu_your_api_key_here

# Quick scan (3 employees, ~90s)
$ jambu quick https://yoursite.com

# Full audit (6 employees, ~3min)
$ jambu audit https://yoursite.com

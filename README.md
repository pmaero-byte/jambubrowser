# Jambubrowser 🌳
### The Sovereign Autonomous Research Agent & Agentic Workspace

Jambubrowser is a world-class, fully local, privacy-first autonomous AI browser and research engine. Unlike standard AI tools, it doesn't just generate text; it **thinks, acts, and evolves** entirely on your own machine. It is designed for elite researchers, security professionals, and power users who require unconstrained internet access with absolute forensic safety.

---

## 🚀 Key Evolutionary Features

- **💎 Premium Hybrid UI**: Split-pane architecture with a persistent Agent Sidebar and a 70%-width immersive browser workspace.
- **⚡ Jambu Snap (Intent Short-Circuit)**: Real-time conversational responses (<0.5s) for simple queries, bypassing the swarm.
- **🐝 Autonomous Swarm Research**: Decomposes complex queries into parallel sub-missions executed by specialized sub-agents.
- **📍 Deep Trust Bridge**: Click any citation in the chat to instantly navigate the browser view to that original source.
- **👁️ Computer Use (Visual Grounding)**: The agent "sees" the page and performs autonomous clicks and actions.
- **🧠 Hybrid RAG Pipeline**: Pinpoint factual accuracy using local vector search (SQLite-vec) and semantic memory.
- **🛠️ Self-Improving Brain**: The agent autonomously builds its own Python skills to solve data extraction bugs.

## 🌟 High-Impact Use Cases

### 1. 🔬 Technical Audits & Market Intel
*   **Use Case**: "Compare NVIDIA Blackwell vs AMD MI350 including memory bandwidth and thermal performance."
*   **Autonomous Flow**: Spawns a 3-agent swarm -> Scrapes whitepapers and benchmark sites -> Synthesizes a side-by-side comparison with source-linked data.

### 2. 🛡️ Sovereign Security Research
*   **Use Case**: Enables researchers to explore non-indexed data via **Tor Routing** without leaving a trace on their local host or revealing their real-world identity.
*   **Safety**: Stateless browser sessions ensure that cookies, cache, and history are destroyed immediately after research.

### 3. 🎓 Academic Synthesis
*   **Use Case**: "Find the last 5 reports on ZK-proof scalability for mobile."
*   **Workflow**: Bypasses paywalls using the **Credential Vault** -> Queries ArXiv/GitHub APIs -> Summarizes findings into a professional research board.

### 4. ⚙️ Web Automation (Computer Use)
*   **Use Case**: "/ground this page and find the 'Export' button."
*   **Action**: The agent uses vision to perceive dynamic JS elements and performs a high-precision click on your behalf.
